# 👩‍💻 Atividades Realizadas:

## 📖 Atividade de aplicação:
- Criar uma página contendo:
  - Um título principal.
  - Três parágrafos.
  - Dois subtítulos.

- Aplicar:
  - Título principal -> ```#titulo-principal ```


  - Subtítulos -> ```.titulo-secao ```


  - Parágrafos -> ```.texto ```
